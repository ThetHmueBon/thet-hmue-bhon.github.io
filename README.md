# Thet Hmue Bhon — Vue 3 Portfolio

A modern developer portfolio based on the supplied Figma design, built with Vue 3 + Vite.

## Stack

- Vue 3
- Vite
- JavaScript
- CSS
- GSAP
- Lucide Vue

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Included interactions

- Responsive navigation
- Smooth section scrolling
- Infinite technology marquee
- Dark / light mode
- `Cmd/Ctrl + K` quick navigation
- Interactive skill categories
- Animated skills orbit
- Project carousel
- Project case-study modal
- Scroll reveal animations
- Contact form UI
- Custom cursor glow

## Next step for Spring Boot

The frontend currently works without a backend. A Spring Boot API can be added later for the contact form, project content management, analytics, or an admin dashboard.
